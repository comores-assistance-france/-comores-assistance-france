MISE À JOUR SUR GITHUB
1. Décompresser l'archive sur votre ordinateur.
2. Ouvrir le dépôt GitHub du site, onglet Code > Ajouter un fichier > Téléverser des fichiers.
3. Sélectionner TOUS les fichiers extraits (pas le ZIP et pas le dossier parent).
4. Accepter le remplacement des fichiers existants et valider Commit changes.
5. Patienter pendant la republication GitHub Pages et actualiser le site (Ctrl + F5).
