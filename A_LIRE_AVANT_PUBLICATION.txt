COMORES ASSISTANCE FRANCE — VERSION 2 — MISE À JOUR GITHUB PAGES
=================================================

Le ZIP contient un site statique autonome : index.html, style.css, app.js,
a-propos.html, confidentialite.html.

CONTENU :
- 10 leçons françaises avec explications faciles et quiz interactifs.
- 1 traduction orale en shingazidja proposée par le porteur du projet,
  clairement signalée comme NON VALIDÉE.
- 9 traductions shingazidja en attente, aucun audio shingazidja fictif.
- Lecture vocale automatique du français (fonction navigateur).
- Liens vers les services administratifs officiels.
- Aucun formulaire de collecte de données ni publicités ajoutées.

SITE DÉJÀ MIS EN LIGNE — VÉRIFICATIONS ET AMÉLIORATIONS :
1. Faire relire la traduction de la première leçon par des locuteurs natifs.
2. Compléter les mentions légales et le contact sur a-propos.html,
   ainsi que la page de confidentialité si nécessaire.
3. Vérifier que les liens officiels ouvrent les bonnes pages et que
   les informations correspondent à la réglementation actuelle.
4. Tester le site sur téléphone et ordinateur, et la lecture vocale.
5. Préparer de vrais enregistrements shingazidja si possible.

MISE À JOUR GITHUB PAGES :
- Décompresser le ZIP sur ordinateur.
- Dans le dépôt GitHub existant, utiliser Add file > Upload files.
- Sélectionner les fichiers contenus dans le dossier décompressé (PAS le ZIP).
- Conserver les fichiers à la racine et valider le commit.
- GitHub Pages republie ensuite automatiquement le site.

La publication et les mises à jour sur GitHub sont effectuées par le propriétaire du compte, pas par ChatGPT.
