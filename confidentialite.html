Confidentialité

Le site ne demande pas de création de compte et ne comporte ni publicité ni outil d’analyse ajouté par le projet. L’atelier shikomori comporte des champs de saisie : les réponses restent sur votre appareil, sauf si vous choisissez de les copier puis de les envoyer vous-même. Les propositions de contribution et les demandes de renseignements sur les ateliers utilisent un lien « mailto: » : votre application de messagerie s’ouvre et vous décidez si vous envoyez un message. Le site ne reçoit pas automatiquement vos informations.

Les recherches, les listes de démarches personnalisées et les réponses aux quiz sont traitées directement dans votre navigateur et ne sont pas envoyées par le code du site à un serveur. La lecture vocale française utilise les fonctions disponibles dans votre navigateur ou appareil ; leur fonctionnement dépend de celui-ci.

Progression des leçons de français : la nouvelle page « Français par niveaux » conserve les exercices réussis uniquement pendant la visite, sauf si vous cochez volontairement l’option d’enregistrement sur cet appareil. Dans ce cas, les résultats sont enregistrés dans le stockage local de votre navigateur (localStorage), sans être envoyés à notre site. Vous pouvez les effacer à tout moment depuis la page d’apprentissage. Sur un appareil partagé, il est préférable de ne pas activer cette option.

L'hébergeur peut traiter des données techniques nécessaires à la fourniture du site, notamment des informations de connexion, selon ses propres règles. Hébergement actuel : GitHub Pages. Cette page devra être adaptée à toute nouvelle fonctionnalité.

Les liens vers des sites officiels ouvrent des services externes avec leurs propres politiques de confidentialité. Si vous envoyez un e-mail, votre fournisseur de messagerie et celui du destinataire traiteront le message selon leurs propres règles. N’envoyez pas de documents sensibles lors du premier contact.
